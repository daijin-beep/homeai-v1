# Feature Implementation Plan Skill

## checks

Before coding, produce:

1. Files to inspect
2. Data contracts affected
3. API routes affected
4. UI states affected
5. Provider interfaces affected
6. Error cases
7. Tests to add or update
8. Migration needs
9. Implementation sequence

Then implement in small steps.

## reject conditions

- Missing shared contract impact analysis.
- Missing tests for behavior changes.
- Hidden product behavior outside task scope.
- PDF, construction communication, or contractor scope creep in V1.

## required output

After implementation, summarize:

- changed files
- commands run
- tests run
- risks
- follow-up work

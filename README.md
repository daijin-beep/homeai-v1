# homeAI V1

homeAI V1 is a spatial foundation, full-space visualization, and soft decor GPS product.

This repository starts with M0 foundation contracts:

- pnpm workspace baseline
- TypeScript strict baseline
- shared Zod contracts
- deterministic mock fixture contracts
- contract validation tests
- AI collaboration guardrails

V1 excludes PDF export, construction communication, contractor collaboration, and professional drawing output.

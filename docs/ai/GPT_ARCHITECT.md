# GPT Architect Review Guide

Review M0 and future tasks against these priorities:

1. V1 scope correctness.
2. Contract completeness.
3. Schema validation.
4. Fixture determinism.
5. Room classification correctness.
6. Mock provider contract clarity.
7. Test baseline.
8. Absence of PDF, delivery, construction, and contractor scope creep.

Reject changes that let LLMs write final geometry, bypass shared schemas, mutate confirmed geometry outside Space Truth Engine, or let render output rewrite walls/windows.
